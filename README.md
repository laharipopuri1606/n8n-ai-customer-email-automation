N8N AI Customer Email Automation

An AI-powered customer email automation workflow built using n8n.

-> Workflow

Customer Email  
↓  
Gmail Trigger  
↓  
Text Classifier  
↓  
AI Agent  
↓  
Gmail Reply  
↓  
Customer

-> Email Categories

- Product Inquiry
- Order
- Return/Refund
- Complaint
- General Inquiry

-> Technologies Used

- n8n
- Gmail
- OpenAI
- AI Agent
- Text Classifier

-> Features

- Automatically receives customer emails
- Classifies emails into different categories
- Generates AI-powered customer replies
- Automatically replies to the original email thread
- Removes the default n8n email attribution

-> Workflow File

The exported n8n workflow is included in this repository.
